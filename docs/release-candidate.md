## Opraveno
- Načítání stránek bez poskakování: patička je při načítání vždy pod ohybem a malé stránky se už nedotahují zvlášť; karta mužstva drží místo pro řádek trenéra a časová osa historie drží výšku, dokud se nenačte.
- Start webu bez šedého mezikroku: úvodní obrazovka s erbem vydrží, dokud se stránka nevykreslí i s písmy a ikonami lišty.
- Přechod mezi stránkami bez šedého problikávání: načítací bloky se ukážou až po 0,4 s čekání a načítání celé stránky vypadá jako start webu (erb v kruhu), na webu i v administraci.
